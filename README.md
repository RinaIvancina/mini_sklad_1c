Учебный проект: 1С и ФГИС Меркурий

Лабораторная работа по разработке конфигурации и интеграции с Ветис.API.

Что добавлено в проект:

1.Справочники:
Справочник «Номенклатура» для хранения перечня товаров.

2.Документы:
Документ «Поступление» (с табличной частью «Товары» и кодом в модуле проведения для движений по регистрам).

3.Документ «Реализация» (с табличной частью «Товары», модулем проведения и кнопкой вывода печатной формы).

4.Регистры накопления:
Регистр остатков (для ведения количественного учета на складе).

5.Регистр оборотов (для сбора данных по продажам).

6.Отчеты:
Отчет «Обороты по товарам» (разработан на базе Схемы компоновки данных — СКД).

7.Печатные формы:
Макет печатной формы для документа «Реализация» и программный код его вызова.

8.Интеграция с Меркурий:
8.1.Настройка параметров подключения в обработке «кб99 ВСД» (заполнение вкладки «Общие параметры» ключами API).

8.2.Создание карточки продукции в справочнике «ВСД продукция элемент».
